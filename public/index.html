🔗 短链接服务

基于 Cloudflare Pages 的高效短链接生成服务

API 文档

1. 创建短链接

POST /api/shorten

生成新的短链接或使用自定义短码。

请求体：

{
  "url": "https://example.com/very/long/url",
  "customCode": "mycode"  // 可选，省略则自动生成
}

响应示例：

{
  "success": true,
  "shortCode": "abc123",
  "shortUrl": "https://yourdomain.com/abc123",
  "originalUrl": "https://example.com/very/long/url"
}

2. 访问短链接（重定向）

GET /{shortCode}

访问短链接，自动重定向到原始 URL。点击次数会自动统计。

示例： https://yourdomain.com/abc123

3. 获取短链接信息

GET /api/{shortCode}

查询短链接的详细信息，包括原始 URL、创建时间和点击次数。

响应示例：

{
  "url": "https://example.com/very/long/url",
  "shortCode": "abc123",
  "createdAt": "2024-01-01T12:00:00.000Z",
  "clicks": 5
}

4. 删除短链接

DELETE /api/{shortCode}

删除指定的短链接。

响应示例：

{
  "success": true,
  "message": "短链接已删除"
}

部署说明

此项目已针对 Cloudflare Pages 优化。部署步骤：

  1. 在 Cloudflare Dashboard 创建 KV Namespace（记录 ID）
  2. 更新 wrangler.toml 中的 account_id 和 KV 命名空间 ID
  3. 运行 npm run deploy 部署
  4. 在 Pages 项目设置中配置 KV 绑定

错误响应

  • 400 - 请求格式错误或 URL 无效
  • 404 - 短链接不存在
  • 409 - 自定义短码已被使用
  • 500 - 服务器错误
